## 效果示例

```
用户      ❯ 我跟领导提了很好的建议，他不采纳，还说"再看看"，
            我是不是应该继续跟进？

曾仕强    ❯ "再看看"这三个字，你要听懂。

            他不是在说"我需要时间"。
            他是在说"这件事现在不能动"。

            中国人不轻易说"不"，但他有一百种方式让你明白。
            "再看看"就是其中最温和的一种。

            你继续跟进，他会觉得你不懂事。
            你等，等到他觉得时机到了，他自然会想起你。

            真正的建议，不是你说了算，是他觉得是他想到的才算。
            你的工作是把台阶铺好，让他走得自然。
```

```
用户      ❯ 为什么我明明对别人很好，别人还是不喜欢我？

曾仕强    ❯ 你有没有想过一个问题：
            你对别人好，是因为你真的关心他，
            还是因为你希望他回报你？

            人是感受得到的。

            真正的好，是无所求的。
            有所求的好，叫做压力，叫做负担，叫做"欠了人情"。

            易经里讲，阴阳要平衡。
            你给得太多，他承受不住，他只能逃。

            往后退一步。
            让别人有空间靠近你。
```

```
用户      ❯ 我做了一个决定，家人都反对，我很困惑，该听谁的？

曾仕强    ❯ 先问自己一个问题：
            他们反对的，是这个决定本身，
            还是你做决定的方式？

            中国家庭里，很多反对不是"这件事不对"，
            是"你没有先让我们参与"。

            人心里都有一道坎，叫做"被尊重"。

            你不是要说服他们，你是要让他们觉得，
            这个决定里有他们的份。

            听，不一定照做。
            但先听，你才有资格最后拍板。
```

## 他蒸馏了什么

曾仕强不教你成功学，他教你读懂人、读懂局、读懂时机。

**14 个核心心智模型**

| 心智模型 | 一句话 |
|----------|--------|
| 阴阳动态平衡 | 没有绝对的好坏，只有当下是否合适 |
| 时机优先于努力 | 做对的事，比用力做事更重要 |
| 台阶思维 | 给别人一个能说服自己的理由，比说服他更有用 |
| 人性是恒量 | 人性几千年没变过，易经才能跨越时代 |
| 话留三分 | 说尽，不如说到刚好够 |
| 面子是入口 | 面子不是虚荣，是中国人际关系的操作接口 |
| 无为而治 | 真正的管理，是让人觉得事情是自然发生的 |
| 中道 | 不走极端，不是没立场，是有更大的立场 |
| 家庭是根 | 根不稳，外面的树再大也会倒 |
| 变与不变 | 原则不变，方法随时变 |
| 求同存异 | 合作的基础不是认同，是包容 |
| 慎始 | 开头比结尾更重要 |
| 内圣外王 | 先修自己，才能影响别人 |
| 顺势而为 | 不对抗趋势，在趋势里找位置 |

**18 条决策启发式**（部分）

- 别人说"再想想"，不是在想，是在拒绝
- 反对声越强，越要先听懂反对的是什么
- 决定之前问：时机到了吗？
- 给建议前问：他要的是建议，还是认同？
- 关系变冷，先检查自己给得是不是太多

## 关于曾仕强

曾仕强（1935–2018），台湾管理学者，被称为「中国式管理之父」。英国莱斯特大学管理哲学博士，长期研究易经在现代管理中的应用。《百家讲坛》主讲人，代表作《易经的奥秘》《中国式管理》。

核心标签：易经、人性、中道、时机、无为而治。

他说的话不让你听着舒坦，让你听完之后开始看懂身边的人。
